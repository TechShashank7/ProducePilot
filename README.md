# ProducePilot

ProducePilot is an AI-native fresh produce operations platform. This monorepo contains the following components:

- `backend/`: Express server, MongoDB models, API routes, and services.
- `frontend/`: React + Vite frontend application.
- `data/`: Data generation and seed scripts for populating dummy inventory and business data.
- `n8n-workflows/`: Automated workflows for external integrations.
- `docs/`: Project documentation.
